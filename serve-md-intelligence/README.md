# SERVE MD Intelligence

Private geographic investment-intelligence system for a Medicare-focused primary-care company.
It identifies, ranks, analyzes and financially models potential expansion markets across the US
using public CMS, Census, HRSA and CDC data.

| Capability | Where |
|---|---|
| Search any city, ZIP code or county and see demographic, Medicare, competition / provider-supply, health-need and economic panels | `/` and `/market/:level/:id` |
| Configurable 0–100 **SERVE MD Score** – every pillar and metric weight, direction, normalization and missing-data policy is editable and versioned | `/score` |
| Expansion-ranking engine over all counties / ZCTAs / places with filters, sorting and CSV export | `/rankings` |
| Interactive choropleth map (score, tooltips, click-through to profile) | `/map` |
| Five-year clinic financial model – editable patients, visits, reimbursement, providers, compensation, staffing, rent, diagnostics, marketing, overhead, growth; outputs revenue, EBITDA, margin, break-even, cash requirement, ROI, IRR, NPV; saved scenarios | `/financial` |
| Registry-driven data pipeline – add a dataset or scoring variable by editing YAML + one loader | `config/metrics.yaml`, `pipelines/` |

> Public aggregate data only. No PHI, patient records or proprietary production data are used anywhere in this system.

## Quick start

```bash
make setup          # python venv + pip install -e ".[dev]"  and  npm install in frontend/
make data-sample    # build a small synthetic warehouse from checked-in fixtures (seconds)
make dev            # API on :8000 (uvicorn --reload) + Vite dev server on :5173
```

Open http://localhost:5173. The Vite dev server proxies `/api` to the FastAPI backend.

To run the production bundle from FastAPI alone:

```bash
cd frontend && npm run build && cd ..
.venv/bin/uvicorn backend.app.main:app --port 8000     # serves frontend/dist + /api
```

### Real data

```bash
make data           # downloads and loads every registered public source (cached under data/raw)
python -m pipelines.build --list          # show registered sources
python -m pipelines.build --source acs5   # (re)load one source
```

See [docs/runbook.md](docs/runbook.md) for details, expected runtimes and troubleshooting.

## Repository layout

```
backend/app/
  api/            FastAPI routes, dependencies, service layer
  data/           DuckDB warehouse schema + read repository
  engines/        scoring, ranking, financial engines (pure functions, fully tested)
  models/         Pydantic contracts shared by API, engines and pipelines
  registry.py     loads/validates config/*.yaml
  tools/          fixture generator, data-dictionary generator
backend/tests/    pytest suite (engines, API, registry)
config/
  metrics.yaml            metric + source registry  (single source of truth)
  scoring_default.yaml    default SERVE MD Score configuration
  financial_default.yaml  default financial-model assumptions
pipelines/        ETL framework + one module per public source; pipelines/tests
frontend/         React 18 + TypeScript + Vite + Tailwind + Recharts + MapLibre GL
data/
  fixtures/       tiny synthetic dataset for tests & offline development (NOT real statistics)
  raw/            cached downloads (gitignored)
  warehouse/      servemd.duckdb (gitignored)
docs/             architecture, methodology, assumptions, data dictionary, runbook, extension guide
```

## Development

```bash
make test      # pytest (backend + pipelines) and vitest (frontend)
make lint      # ruff check/format, eslint, tsc
make fmt       # auto-format python
make docs      # regenerate docs/data-dictionary.md
```

All work lands through feature branches and pull requests; CI (`.github/workflows/ci.yml`) runs
lint, type-check, tests and the frontend build on every PR.

## Configuration

Every setting in `backend/app/settings.py` can be overridden with a `SERVEMD_*` environment
variable or a `.env` file, e.g.

```
SERVEMD_ACCESS_TOKEN=change-me      # enables shared-secret auth (X-Access-Token header); empty = open (local dev)
SERVEMD_WAREHOUSE_PATH=/data/servemd.duckdb
SERVEMD_CORS_ORIGINS=["https://intel.servemd.example"]
```
